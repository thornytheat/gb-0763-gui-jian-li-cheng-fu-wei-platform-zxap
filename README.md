# 轨检里程复位台

轨道巡检员用它把列车测距回填到各链的标称里程。覆盖长度按计划轨段取并集，掉线窗口、倒走报文和断链两侧可分开复核。

使用 `docker compose up --build`，打开 `http://localhost:18462/`。本机可安装 `requirements.txt` 后运行 `flask --app app.main:create_app run --port 18462`，执行 `pytest -q` 验证。归档数据保存在 `TRACK_DB` 指向的 SQLite 文件内，修改路径可使用一个空档案库。

从首页的夜巡原始报文开始，依次查看报文采信、基点匹配、坐标复位、缺陷归并、覆盖对账和维修项销项。选择标定对照报文可以复核完整覆盖。进入批次页归档，重复提交相同输入可取回同一批次，再从签发页下载证据单。前六项 API 支持 GET 读取样例，也支持 POST 提交 `{"csv":"…","repairs":[…]}` 自有报文与维修项记录。

修后复巡常常只走过维修项的一截。维修项销项只认维修完成之后复位出来的覆盖，并逐段截到复巡仍在报缺的位置：已验的一截可先销，越过报缺的里程恢复待修。迟到记录在已销位置重新报缺时，该段随重算退回待修；批次页可查历次裁定，归档失败整笔回滚可重试，重跑同批不重复销项。
